# Docs Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Takumi docs around the IA in `2026-05-22-docs-ia-refactor-design.md`. Move from 18 pages to ~50, fill every documented gap, split the 650-line `reference.mdx` into AutoTypeTable-driven entrypoint pages, no dead links.

**Tech Stack:** fumadocs-core, fumadocs-ui, fumadocs-mdx, fumadocs-twoslash, fumadocs-typescript (new), Waku, Tailwind, beautiful-mermaid, Vercel.

**Branch:** Already on `docs/refactor`.

- `VERIFY-DEV`: `cd docs && bun run dev`, then visit listed URLs in browser, confirm rendered output + no console errors.
- `VERIFY-LINKS`: from `docs/`, run `bun x linkinator http://localhost:3000/docs --skip "^https?://(?!localhost)"` after starting dev server. Zero broken internal links.
