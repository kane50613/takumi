Copy an Open Graph card into your project, then edit its content and styles. The [shadcn CLI](https://ui.shadcn.com/docs/cli) adds the card and installs `takumi-js`.

```npm
npx shadcn@latest add https://takumi.kane.tw/r/image/blog-post.json
```

To add items by name, register the namespace in `components.json`:

```json title="components.json"
{
  "registries": {
    "@takumi": "https://takumi.kane.tw/r/{name}.json"
  }
}
```

```npm
npx shadcn@latest add @takumi/image/blog-post
```

Every item lives under `image/`. Cards land in `components/takumi/image/`.

## A route that answers with an image

`image/og-route` adds a Next.js route handler and the blog post card it renders. The route serves `/og` and reads the card's text from the query string.

```npm
npx shadcn@latest add @takumi/image/og-route
```

```tsx title="app/og/route.tsx"
import { ImageResponse } from "takumi-js/response";

import BlogPostTemplate from "@/components/takumi/image/blog-post";

export function GET(request: Request) {
  const { searchParams } = new URL(request.url);

  return new ImageResponse(
    <BlogPostTemplate
      author={searchParams.get("author") ?? "Takumi"}
      category={searchParams.get("category") ?? "Engineering"}
      date={searchParams.get("date") ?? "Today"}
      title={searchParams.get("title") ?? "Hello from Takumi"}
    />,
    { width: 1200, height: 630 },
  );
}
```

Point a page's Open Graph image at the route:

```tsx title="app/blog/[slug]/page.tsx"
import type { Metadata } from "next";

type Props = { params: Promise<{ slug: string }> };

export async function generateMetadata({ params }: Props): Promise<Metadata> {
  const { slug } = await params;

  return {
    openGraph: { images: [`/og?title=${encodeURIComponent(slug)}`] },
  };
}
```

A relative image URL needs `metadataBase` in the root layout's metadata, or `next build` fails:

```tsx title="app/layout.tsx"
export const metadata = { metadataBase: new URL("https://example.com") };
```

The CLI rewrites the `@/` import to the alias in your `components.json`. A project on `~/` gets `~/components/takumi/image/blog-post`.

The route is for the Next.js App Router. The shadcn CLI skips it when it cannot detect the framework, and moves it to another folder in Pages Router, React Router, and Laravel projects, where it does not work as a route.
