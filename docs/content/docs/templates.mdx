Takumi ships ready-made templates. Use one as a starting point, or as-is.

Install with the [shadcn CLI](https://ui.shadcn.com/docs/cli), or [download from the latest commit](https://github.com/kane50613/takumi/tree/master/takumi-template/src/templates).

## Blog Post Template

A blog post card with a large title and a subtitle.

![Blog Post Template](/templates/previews/blog-post-template.webp)

```npm
npx shadcn@latest add https://takumi.kane.tw/templates/registry/blog-post-template.json
```
