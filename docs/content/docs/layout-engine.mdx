Takumi runs [Taffy](https://github.com/DioxusLabs/taffy) for real CSS layout: Flexbox, Grid, and block, with browser defaults. You write the CSS you already know.

## Coming from satori

|                          | satori                 | Takumi                                |
| :----------------------- | :--------------------- | :------------------------------------ |
| Layout modes             | Flexbox only           | Flex, Grid, block                     |
| Element default          | Forces `display: flex` | Browser defaults (`<div>` is `block`) |
| `flex-direction` default | `column`               | `row`                                 |

A satori template that leaned on forced flex needs `display: flex` written out, and a row layout no longer needs `flex-direction: row` undone. Everything else ports over.

## Driving the canvas

The `width` and `height` you pass to the render set the pixel canvas. The root node won't fill it on its own, so give the root `width: 100%` and `height: 100%` for a full-bleed image.

```tsx
await render(<div style={{ width: "100%", height: "100%" }}>Full bleed</div>, {
  width: 1200,
  height: 630,
});
```

Omit `width` or `height` and the node sizes to its content. This works on the render too: drop `height` and the image grows to fit.

```tsx
// no height: the image grows to fit the rows
await render(<div style={{ width: "100%", padding: 48 }}>{rows}</div>, { width: 1200 });
```

An `<img>` measures to its intrinsic size unless you set `width` and `height`. `position: fixed` resolves against the canvas, not a scroll viewport.
