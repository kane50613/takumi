## Node Types

Every node is a `container`, `text`, or `image`.

All nodes accept these fields:

<TypeTable
  type={{
    tagName: {
      type: "string",
      description: "Element tag name used for HTML preset and selector matching",
    },
    className: {
      type: "string",
      description: "Element class name used for selector matching",
    },
    id: {
      type: "string",
      description: "Element id used for selector matching",
    },
    attributes: {
      type: "NodeAttributes",
      description: "Extra element attributes used for selector matching",
    },
    preset: {
      type: "Style",
      description: "Default HTML element styles (lowest priority)",
      typeDescriptionLink: "#style-properties",
    },
    tw: {
      type: "string",
      description: "Tailwind classes (medium priority, overrides preset)",
    },
    style: {
      type: "Style",
      description: "Inline styling properties (highest priority)",
      typeDescriptionLink: "#style-properties",
    },
    lang: {
      type: "string",
      description: "BCP-47 language tag; inherited by descendants, drives locale-aware shaping",
    },
    dir: {
      type: '"ltr" | "rtl"',
      description: "Text direction; inherited by descendants",
    },
  }}
/>

### Container

Groups other nodes and arranges them in a layout. Adds:

<TypeTable
  type={{
    children: {
      type: "Node[]",
      description: "Children nodes",
    },
  }}
/>

### Text

Displays text. Adds:

<TypeTable
  type={{
    text: {
      type: "string",
      required: true,
      description: "Text content to be displayed",
    },
  }}
/>

### Image

Displays a rasterized image or SVG. Adds:

<TypeTable
  type={{
    src: {
      type: "string | Uint8Array | ArrayBuffer",
      required: true,
      description: "Source URL, persistent image key, or raw image bytes",
    },
    width: {
      type: "number",
      description: "Overwrite the intrinsic width of the image",
    },
    height: {
      type: "number",
      description: "Overwrite the intrinsic height of the image",
    },
  }}
/>

## Style Properties

Properties use their camelCase names. Longhands are listed in parentheses. `Supported` means the property follows its CSS spec; a value cell instead lists the accepted keywords.

### Layout & display

| Property                              | Values                                                                                  |
| :------------------------------------ | :-------------------------------------------------------------------------------------- |
| `display`                             | `none`, `flex`, `inline-flex`, `grid`, `inline-grid`, `block`, `inline-block`, `inline` |
| `position`                            | `relative`, `absolute`, `static`, `fixed`                                               |
| `direction`                           | Supported                                                                               |
| `float`                               | Supported                                                                               |
| `clear`                               | Supported                                                                               |
| `zIndex`                              | Supported                                                                               |
| `order`                               | Supported                                                                               |
| `overflow` (`overflowX`, `overflowY`) | `visible`, `clip`, `hidden`                                                             |
| `objectFit`                           | Supported                                                                               |
| `objectPosition`                      | Supported                                                                               |
| `boxSizing`                           | Supported                                                                               |
| `visibility`                          | `visible`, `hidden`                                                                     |
| `content`                             | Supported                                                                               |

explicit setting wins on a tag conflict. `alternates` and `emoji` are not supported. Features apply

capitals from scaled capitals).
