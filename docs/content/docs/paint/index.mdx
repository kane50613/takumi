Use `takumi-paint` when you want the laid-out boxes, text runs, and images and plan to draw them with your own renderer. You can draw the tree on Canvas, write it into editable slides such as PPTX, or pass it to a native drawing API.

`takumi-paint` shares one layout engine, a port of Chromium's layout, with [image output](/docs) and [PDF output](/docs/pdf). Those produce pixels or pages. `takumi-paint` returns a paint tree that says what to draw, where, and in which order, with every CSS value resolved.


## Read the nodes

`tree.nodes` lists every node in document order.

```tsx twoslash title="inspect.tsx"
import { paint } from "takumi-paint";

const tree = await paint(
  <div id="card" style={{ width: 240, padding: 16, background: "#F7F3EC" }}>
    Hello <b>world</b>
  </div>,
  { width: 320 },
);

const card = tree.nodes.find((node) => node.type === "box" && node.element?.id === "card");
console.log(card?.drawables[0]); // { type: "fill", role: "background", shape: { type: "rect", … }, … }

for (const node of tree.nodes) {
  if (node.type !== "text") continue;
  for (const run of node.runs) console.log(run.text, run.element?.tagName, run.font.family); // [!code highlight]
}
```

| Node    | Holds                                                    |
| ------- | -------------------------------------------------------- |
| `box`   | A CSS box: its background, border, shadows, and children |
| `text`  | One paragraph, as shaped runs in visual order            |
| `image` | A replaced image, such as `<img>` or an SVG              |

<Callout type="info">
  Lengths are in device pixels. `devicePixelRatio` scales CSS lengths during layout.
</Callout>

`tree.toJSON()` returns the tree as plain JSON, without font files, so you can hand it to another process.

## Reuse a painter

`paint()` uses one shared `Painter`. Create your own `Painter` to keep a separate font registry, and call `free()` to release its WebAssembly memory.

```tsx twoslash title="painter.tsx"
import { Painter } from "takumi-paint";

const painter = new Painter();
try {
  const tree = await painter.paint(<p>Hello</p>, { width: 320 });
  console.log(tree.height);
} finally {
  painter.free();
}
```

`Painter` also has `registerFont()`, `unregisterFont()`, and `clearFonts()`, and takes the same `fontCacheMaxBytes` option as [`PdfRenderer`](/docs/pdf#reuse-a-renderer).

## Runtimes

`takumi-paint` has the same entries as `takumi-pdf`, which are the default import, `takumi-paint/next`, and `takumi-paint/no-init` with `takumi-paint/wasm-url`. See [Runtimes](/docs/pdf#runtimes).
