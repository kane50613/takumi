## `paint()` and `Painter`

`paint(node, options)` lays out JSX, an HTML string, or a node tree with a shared `Painter` and resolves to a [`PaintTree`](#painttree).

| Member                         | Behavior                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| `new Painter()`                | Creates a painter with the bundled fallback fonts            |
| `painter.paint(node, options)` | Same as `paint()`, with this painter's fonts                 |
| `painter.registerFont(font)`   | Registers a font ahead of time, deduped against earlier ones |
| `painter.free()`               | Releases the painter's WebAssembly memory                    |

## `PaintTree`

| Member            | Value                                              |
| ----------------- | -------------------------------------------------- |
| `width`, `height` | Canvas size in device pixels                       |
| `fonts`           | Every font instance the runs were shaped with      |
| `root`            | The root [`PaintNode`](#paintnode)                 |
| `[...tree]`       | Every node in paint order, parents before children |
| `textRuns()`      | Every run in paint order, as `{ run, node }`       |
| `find(id)`        | The first node whose source `id` matches           |

## Value formats

| Value                                                  | Form in the tree                                   |
| ------------------------------------------------------ | -------------------------------------------------- |
| Colors                                                 | `[r, g, b, a]`, each `0` to `255`                  |
| Matrices                                               | `[a, b, c, d, e, f]`                               |
| Corner radii                                           | `[x, y]` pairs from the top-left corner, clockwise |
| Border sides                                           | Arrays ordered top, right, bottom, left            |
| Linear and radial gradients                            | Resolved stops and geometry                        |
| Conic gradients                                        | CSS text                                           |
| `filter`, `backdrop-filter`, `mask-image`, `clip-path` | CSS text under `unresolvedEffects`                 |
