Load a font for every script your text uses.

<Callout type="warn">
  Takumi never reads system fonts. The only built-in font is Geist, which covers Latin at weights
  300 to 800 and comes last in every fallback chain. Generic families such as `sans-serif` resolve
  to the fonts you load.
</Callout>

## Loading fonts

### The `fonts` option

Pass the fonts a render needs through `fonts`. Each entry takes one of three forms:

| Entry      | Resolves to                                                      |
| ---------- | ---------------------------------------------------------------- |
| URL string | Fetched on demand, keyed by the URL. <sup>1</sup>                |
| Raw bytes  | A `Uint8Array`, `ArrayBuffer`, or `Buffer`, registered directly. |
| Descriptor | `{ name, data, weight, style, generic, cache }`. <sup>2</sup>    |

<sup>1</sup> Name, weight, and style come from the file.

<sup>2</sup> A descriptor's fields override what the file reports.

`render`, `renderSvg`, `renderAnimation`, `measure`, and `ImageResponse` all take `fonts`. It also takes a promise of the list, so pass `googleFonts(...)` without `await`. The renderer decodes each file once and keeps it until you [release it](#releasing-fonts), or until the renderer [evicts it](/docs/caching#release-fonts) to make room. Among equally matching faces of one family that cover the character, the one listed last wins, as a later `@font-face` rule does.

```tsx twoslash title="Load a font URL"
import { ImageResponse } from "takumi-js/response";

export function GET() {
  return new ImageResponse(<div>Hello Takumi</div>, {
    fonts: ["https://example.com/Inter.woff2"], // [!code highlight]
  });
}
```

A descriptor's `data` is raw bytes or a function that returns them:

```tsx twoslash title="Override font metadata"
import { ImageResponse } from "takumi-js/response";

export function GET() {
  return new ImageResponse(<div>Hello Takumi</div>, {
    fonts: [
      {
        name: "Inter",
        weight: 700,
        data: () => fetch("https://example.com/Inter.woff2").then((res) => res.arrayBuffer()),
      },
    ],
  });
}
```

`generic` assigns the font to a CSS generic family keyword. A stack that ends in `monospace` or `serif` then reaches the font without naming it. This is how Tailwind's `font-mono` finds it:

```tsx twoslash title="Assign a generic font family"
import { ImageResponse } from "takumi-js/response";

export function GET() {
  return new ImageResponse(<div tw="font-mono">let x = 1;</div>, {
    fonts: [
      {
        name: "Geist Mono",
        generic: "monospace", // [!code highlight]
        data: () => fetch("https://example.com/GeistMono.woff2").then((res) => res.arrayBuffer()),
      },
    ],
  });
}
```

### From Google Fonts

```tsx twoslash title="Load multilingual fonts"
import { render } from "takumi-js";
import { googleFonts } from "takumi-js/helpers";

const image = await render(<div style={{ fontFamily: "Inter" }}>Hello 你好 こんにちは</div>, {
  width: 1200,
  height: 630,
  // [!code ++]
  fonts: googleFonts(["Inter", "Noto Sans JP", "Noto Sans TC"]),
});
```

`googleFonts` makes one CSS request for all the families. Font files download only when the text needs them, as [subsetting](#subsetting) describes. Use the family name in `fontFamily`.

Pass an object instead of a name to set a family's weight, style, or variable axes:

```tsx twoslash title="Choose font weights and axes"
import { googleFonts } from "takumi-js/helpers";

await googleFonts([
  {
    name: "Inter",
    weight: [400, 700],
    style: "italic",
  },
  {
    name: "Noto Sans JP",
    weight: "600..700", // range loads the variable font
  },
  {
    name: "Fraunces",
    weight: "100..900",
    axes: { opsz: "9..144" }, // vary the optical-size axis too
  },
]);
```

| Field     | Accepts                                     | Effect                                                                   |
| --------- | ------------------------------------------- | ------------------------------------------------------------------------ |
| `name`    | a family name                               | The family to load. <sup>1</sup>                                         |
| `weight`  | a weight, an array, or a range `"100..900"` | Which weights to fetch. <sup>2</sup>                                     |
| `style`   | `"normal"`, `"italic"`, or both             | Which styles to fetch. <sup>3</sup>                                      |
| `axes`    | `{ tag: value \| "min..max" }`              | Variable axes to load, such as `{ opsz: "9..144" }`. <sup>4</sup>        |
| `generic` | a CSS generic family keyword                | Every loaded subset claims it, so `font-mono` can resolve to the family. |

<sup>1</sup> Known families autocomplete their weights and axes.

<sup>2</sup> `weight` defaults to `400`. A range loads the variable font, and `font-weight` drives
it.

<sup>3</sup> `style` defaults to `"normal"`.

<sup>4</sup> An axis given as a range stays variable.

Pass an object instead of an array for request options:

```ts twoslash title="Limit font requests"
import { googleFonts } from "takumi-js/helpers";

const fonts = await googleFonts({
  families: ["Inter"],
  timeout: 3000, // [!code highlight]
});
```

| Option     | Accepts                     | Effect                                                                         |
| ---------- | --------------------------- | ------------------------------------------------------------------------------ |
| `families` | the list above              | The families to load, in fallback priority order.                              |
| `display`  | a `font-display` value      | Sent as `display` in the CSS request.                                          |
| `text`     | a string                    | Loads one file for each face, holding just these characters. <sup>1</sup>      |
| `cache`    | `"auto"` or `"none"`        | Whether a renderer keeps the subsets. See [Fonts used once](#fonts-used-once). |
| `store`    | a download store, or `null` | Keeps the CSS and font files. <sup>2</sup>                                     |
| `baseUrl`  | a css2 endpoint             | Point at a mirror such as `https://fonts.bunny.net/css2`.                      |

<sup>1</sup> See [Fonts for known text](#fonts-for-known-text).

<sup>2</sup> By default, one store of up to 32 MiB for each `fetch` function. A `Map` passed as
`cache` still caches CSS, but is deprecated.

`googleFonts` also takes the [fetch options](/docs/images#fetch-limits): `timeout`, `signal`, `maxBytes`, `allowUrl`, and `fetch`. The timeout covers each request on its own, first the CSS request and then each font file. It does not cover the whole render.

[Caching](/docs/caching#google-fonts-downloads) covers the store that keeps the CSS and font files.

#### Fonts for known text

When you know the text before you load the fonts, pass it as `text`. Google then answers with one file for each face that holds those characters, plus the ones shaping them needs:

```tsx twoslash title="Load only the title's characters"
import { render } from "takumi-js";
import { googleFonts } from "takumi-js/helpers";

const title = "東京の夜景";

const image = await render(<div style={{ fontFamily: "Noto Sans JP" }}>{title}</div>, {
  width: 1200,
  height: 630,
  fonts: googleFonts({ families: ["Noto Sans JP"], text: title }), // [!code highlight]
});
```

Different text loads a different file, and the same characters in any order load the same one. Past 6000 characters once URL-encoded, Google stops honoring `text`, so `googleFonts` leaves it out and loads the `unicode-range` subsets instead.

`text` costs a download for every new set of characters, while the subsets stop downloading once a renderer holds the ones your text uses. Choose by where the renderer runs:

- On Workers and other short-lived isolates, or for a few titles that repeat, use `text`. A cold start downloads one small file, about 16 KB for a Japanese title, instead of every subset the text touches.
- On a long-running server that renders varied text, leave `text` out. After the first renders, the subsets the renderer holds cover most new text.

Put all the text a render shows in one `text`. Splitting a run of Arabic, Devanagari, or another script that shapes its letters across two requests puts the letters in different files, and shaping breaks between them.

### From `@font-face` rules

An `@font-face` rule in `css` or a `<style>` element loads its font as a browser does. `render`, `ImageResponse`, and each renderer's `prepare()` download the `src` files the text reaches, and skip the rest.

```tsx twoslash title="Load a font from CSS"
import { render } from "takumi-js";

const image = await render(<div style={{ fontFamily: "Brand" }}>Hello</div>, {
  width: 1200,
  height: 630,
  // [!code ++:6]
  css: `
    @font-face {
      font-family: Brand;
      src: url("https://example.com/Brand.woff2") format("woff2");
    }
  `,
});
```

The rule's descriptors, such as `font-weight`, `unicode-range`, and `size-adjust`, apply as they do in Chrome. When a `src` fails to download, the rule moves on to its next source for that render, and the next `prepare()` tries the file again. A `local()` source names a font you loaded through `fonts`, by its full name or PostScript name. Takumi downloads the files with the `fetch`, `timeout`, `maxBytes`, and `allowUrl` you pass in `images`, so a relative URL needs your own `fetch`. The renderer keeps the files in its [download store](/docs/caching#downloaded-bytes).

A renderer's `render()` called without `prepare()` downloads nothing. It draws with the `@font-face` files the renderer already holds, and falls back past the rest.

### Fonts in CI and offline renders

Bundle font files when a render must work without Google Fonts:

```tsx twoslash title="Fonts in CI and offline renders"
import { readFile } from "node:fs/promises";
import { render } from "takumi-js";

const inter = await readFile(new URL("./fonts/Inter.woff2", import.meta.url));

const image = await render(<div style={{ fontFamily: "Inter" }}>Hello</div>, {
  fonts: [{ name: "Inter", data: inter }],
});
```

Retries recover a brief outage. They do not help when the host is down or the CI network blocks it. Run unit tests against local files or an injected `fetch`, and test the live service separately. An outer test or route timeout can end the render before the font timeout does. Set `timeout` below that outer limit, and leave time for layout and encoding.

CJK families can have many coverage subsets. Takumi downloads only the subsets your text uses, in the families and weights it is set in. A timeout during `await googleFonts(...)` comes from the CSS request, before any font file downloads.

### Subsetting

`render` registers only the subsets the content draws. The same `fonts` list works for any text, and unused ranges never download. This runs on every render.

| Font kind                           | Behavior                                                                                                  |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Ranged subsets (from `googleFonts`) | Kept only when font matching reaches them for a character, as a browser downloads a `unicode-range` face. |
| Whole files (URL string, raw bytes) | No `unicode-range`, so they always load.                                                                  |

Takumi reads the text after styles apply, so generated content and `text-transform` count, and so does the text inside SVG images, such as chart labels. Each character goes through its own font stack. With `font-family: Inter, "Noto Sans JP"`, Latin text loads only Inter's Latin subset, and a weight loads only when text uses it.

Before a subset downloads, font matching knows only the weight and style declared for it. A subset declared without them counts as normal, so a variable font's other weights only match it after it loads.

### Preloading with `registerFont`

To load fonts before the first request, register them on a renderer. Then pass that renderer to each render. `registerFont` takes the same entries as `fonts` and returns the families it added.

```tsx twoslash title="Preload a local font"
import { readFile } from "node:fs/promises";
import { Renderer } from "takumi-js/node";
import { ImageResponse } from "takumi-js/response";

const inter = await readFile(new URL("./fonts/Inter.woff2", import.meta.url));
const renderer = new Renderer();

await renderer.registerFont({ name: "Inter", data: inter }); // [!code highlight]

export function GET() {
  return new ImageResponse(<div style={{ fontFamily: "Inter" }}>Hello Takumi</div>, {
    width: 1200,
    height: 630,
    renderer, // [!code highlight]
  });
}
```

### Releasing fonts

A renderer keeps every font it loads. Release the ones you no longer need:

```ts
renderer.unregisterFont({ name: "Inter" }); // every face and subset of Inter
renderer.clearFonts(); // back to the built-in Geist
```

A later render that lists a released font loads it again. The renderer also evicts the fonts that renders' lists load when it needs room, one file at a time. Cap them with the [`fonts` budget](/docs/caching#release-fonts).

### Fonts used once

A font in the `fonts` list takes a `cache` mode, as an image does. `"none"` lets the renderer drop a font it loaded for a render once that render settles, so a font that one render needs does not push out fonts that many renders share. A render still uses a font the renderer already holds, and leaves it there:

```tsx twoslash title="Drop a font after its render"
import { render } from "takumi-js";
import { googleFonts } from "takumi-js/helpers";

declare const title: string;
// ---cut---
const image = await render(<div style={{ fontFamily: "Noto Sans JP" }}>{title}</div>, {
  width: 1200,
  height: 630,
  fonts: googleFonts({ families: ["Noto Sans JP"], text: title, cache: "none" }), // [!code highlight]
});
```

A font another render is using stays until the last of them settles. A render without `"none"` that uses the font keeps it. The downloaded file still goes to the [download store](/docs/caching#downloaded-bytes), so the next render that needs it skips the download. Set the store to `null` to keep neither.

## Choosing a font

### Fallback chain

`fontFamilies` is the ordered list of families to try when a glyph is missing. Set it to choose which family wins and what backs it up.

```tsx twoslash title="Choose font fallback order"
import { render } from "takumi-js";
import { googleFonts } from "takumi-js/helpers";

const image = await render(<div>Hello こんにちは</div>, {
  fonts: googleFonts(["Inter", "Noto Sans JP"]),
  fontFamilies: ["Inter", "Noto Sans JP"], // [!code highlight]
});
```

Without `fontFamilies`, the chain is the render's `fonts` in list order. A render without `fonts` uses every registered family in registration order. Geist always comes last.

A missing glyph walks the chain until a family covers it. `googleFonts` registers every subset under its family name with its `unicode-range`. Each character then uses the subset that covers it, as in a browser.

### Variable axes & OpenType features

Set font axes with `font-variation-settings` and OpenType features with `font-feature-settings`. In a variable font, `font-weight` drives the `wght` axis and `font-stretch` drives `wdth`. Kerning is on by default, and `font-kerning: none` turns it off.

```tsx title="Set axes and OpenType features"
<div
  style={{
    fontFamily: "Fraunces",
    fontVariationSettings: "'opsz' 72, 'wght' 700",
    fontFeatureSettings: "ss01",
  }}
>
  Variable Font Text
</div>
```

Register a variable font once, with no `weight`, to keep its axes live:

```tsx title="Register a variable font"
// a `weight` here pins the file to that instance instead
await renderer.registerFont({ name: "Fraunces", data: variableWoff2 });
```

`googleFonts` does this for you. A weight range or an `axes` entry fetches the variable file and leaves its axes free.

<Callout>
  Which axes a file exposes depends on the build. Google Fonts fixes the axes you did not request at
  their defaults, so `Fraunces` from there exposes only `opsz` and `wght`. Other builds keep `SOFT`
  and `WONK` live, and setting them changes the letterforms.
</Callout>

### Synthetic bold & italic

When a family lacks the weight or style you asked for, Takumi draws a synthetic bold or oblique. `font-synthesis` controls this.

```tsx title="Synthetic bold & italic"
<div style={{ fontFamily: "Inter", fontSynthesis: "none" }}>No faux bold</div>
```

List `weight`, `style`, `small-caps`, or any mix of them to allow each one. `none` turns them all off, so a missing bold weight draws at regular weight.
