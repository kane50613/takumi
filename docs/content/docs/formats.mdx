---
title: Output formats
description: Choose PNG, JPEG, WebP, ICO, raw pixels, or SVG output and set its quality, resolution, and cancellation.
---

`render()` returns encoded bytes, and the `format` option chooses the encoder.

## Picking a format

```tsx twoslash title="Choose an image encoder"
import { render } from "takumi-js";

const card = <div tw="w-full h-full grid place-items-center bg-white">Hello Takumi</div>;

// [!code highlight:3]
const png = await render(card, { width: 1200, height: 630, format: "png" });
const jpeg = await render(card, { width: 1200, height: 630, format: "jpeg", quality: 80 });
const webp = await render(card, { width: 1200, height: 630, format: "webp", quality: 80 });
```

| Format          | Alpha | `quality` | `lossless` | Notes                                                              |
| :-------------- | :---- | :-------- | :--------- | :----------------------------------------------------------------- |
| `png` (default) | Yes   | No        | No         | Lossless. Use it for transparency or exact pixels.                 |
| `jpeg`          | No    | Yes       | No         | Lossy. Draw an opaque background, since JPEG has no alpha channel. |
| `webp`          | Yes   | Yes       | Yes        | Lossless unless you set `quality`. `lossless: true` wins.          |
| `ico`           | Yes   | No        | No         | Favicon file. At most 256 × 256 pixels.                            |
| `raw`           | Yes   | No        | No         | Uncompressed RGBA bytes, `width × height × 4`.                     |

`quality` runs from `0` to `100` and defaults to `75`. Formats marked No in the `quality` column ignore it.

<Callout type="info">
  On the WebAssembly backend, WebP is always lossless. `quality` and `lossless` are accepted but
  have no effect on WebP. `quality` still applies to JPEG.
</Callout>

### Raw frames

`format: "raw"` skips encoding and returns the RGBA buffer, which you can feed to ffmpeg or another encoder. The [Animation](/docs/animation) page streams raw frames into ffmpeg to make a video.

## Device pixel ratio

`devicePixelRatio` sets how many image pixels each CSS pixel takes. `width` and `height` stay the image size in pixels. To render a 1200 × 630 design at twice the resolution, double the size and set the ratio to `2`:

```tsx twoslash title="Render at twice the resolution"
import { render } from "takumi-js";

const image = await render(<div tw="w-full h-full text-6xl">Hello Takumi</div>, {
  width: 2400,
  height: 1260,
  devicePixelRatio: 2, // [!code highlight]
});
```

The result is a 2400 × 1260 image. Every CSS length draws twice as large, so the layout matches a 1200 × 630 render at ratio `1`.

<Callout type="warn">
  With `width: 1200` and `height: 630` at ratio `2`, the image stays 1200 × 630 and the layout gets
  only 600 × 315 CSS pixels.
</Callout>

## Dithering

`dithering` adds ordered Bayer noise to gradient fills before they drop to 8-bit color, which removes visible banding. It applies to `render()`, including `raw` output. It accepts these values:

- `none` (default)
- `ordered-bayer`

```tsx twoslash title="Reduce gradient banding"
import { render } from "takumi-js";

const image = await render(<div tw="w-full h-full bg-linear-to-r from-slate-900 to-slate-700" />, {
  width: 1200,
  height: 630,
  dithering: "ordered-bayer", // [!code highlight]
});
```

## Animated output

`renderAnimation()` encodes a sequence of scenes as WebP, APNG, or GIF. See [Animation](/docs/animation).

## Vector SVG

`renderSvg()` returns an SVG document string instead of a bitmap. It draws real `<rect>`, `<path>`, gradients, glyph outlines, and embedded images from the same layout.

```tsx twoslash title="Render PNG and SVG"
import { render, renderSvg } from "takumi-js";

const card = <div>Hello Takumi</div>;

const png = await render(card, { width: 1200, height: 630 });
const svg = await renderSvg(card, { width: 1200, height: 630 }); // [!code highlight]
```

SVG is a vector format, so these raster options do not apply to it:

- `format`
- `quality`
- `lossless`
- `dithering`
- `drawDebugBorder`
- `devicePixelRatio`

## Cancellation

Pass an `AbortSignal` as `signal` to cancel a render. Takumi checks it before work starts and again after fonts and images load. An aborted signal stops the render with the signal's reason, and it also cancels image fetches that are still running.

```tsx twoslash title="Cancel with the request"
import { ImageResponse } from "takumi-js/response";

export function GET(request: Request) {
  return new ImageResponse(<div>Hello Takumi</div>, {
    width: 1200,
    height: 630,
    signal: request.signal, // [!code highlight]
  });
}
```
