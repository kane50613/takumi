---
title: The measure() API
description: Measure node dimensions and text runs with Renderer.measure() before rendering an image.
icon: Ruler
---

`measure()` returns a node's laid-out size without rendering it. Use it to fit a headline into a fixed width, or to place a badge against the measured box.

```tsx twoslash tab="takumi-js/node" title="Measure with the native renderer"
import { Renderer } from "takumi-js/node";
import { fromJsx } from "takumi-js/helpers/jsx";

const renderer = new Renderer();
const { node, css } = await fromJsx(<span tw="text-xl">I'm a text node</span>);

const { width, height } = await renderer.measure(node, { css }); // [!code highlight]
//      ^?
```

```tsx twoslash tab="takumi-js/wasm" title="Measure with WebAssembly"
import { Renderer } from "takumi-js/wasm";
import { fromJsx } from "takumi-js/helpers/jsx";

const renderer = new Renderer();
const { node, css } = await fromJsx(<span tw="text-xl">I'm a text node</span>);

const { width, height } = await renderer.measure(node, { css }); // [!code highlight]
//      ^?
```

## Returned fields

`measure()` resolves to a `MeasuredNode`.

<TypeTable
  type={{
    width: {
      type: "number",
      description: "Laid-out width",
    },
    height: {
      type: "number",
      description: "Laid-out height",
    },
    transform: {
      type: "[number, number, number, number, number, number]",
      description: "Transformation matrix that places the box on the page",
    },
    children: {
      type: "MeasuredNode[]",
      description: "Measured child nodes",
    },
    runs: {
      type: "MeasuredTextRun[]",
      description: "Text runs the node lays out",
      typeDescriptionLink: "#text-runs",
    },
  }}
/>

Every length is a device pixel. A `20px` box measures `40` under a `devicePixelRatio` of `2`.

## Text runs

A node that lays out text reports one `MeasuredTextRun` per shaped run.

<TypeTable
  type={{

    x: {

      description: "Left edge, measured from the content box of the node that owns the run",
    },
    y: {
      type: "number",
      description: "Top edge, measured from the content box of the node that owns the run",
    },
    width: {
      type: "number",
      description: "Run width",
    },
    height: {
      type: "number",
      description: "Run height",
    },
  }}
/>

## Coordinates

`transform` is absolute. It places the box on the page, and every node carries one, including the
boxes takumi generates to lay out inline content.

A run's `x` and `y` are not absolute. They start at the content box of the node that owns the run,
so add that node's `padding` and `border` to place a run on the page.
