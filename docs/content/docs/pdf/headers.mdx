---
title: Headers & footers
description: Repeat headers, footers, and page numbers on every PDF page, and size the margins they need.
icon: PanelTop
---

Pass JSX, an HTML string, or a node tree to `header` or `footer`. The band repeats in the top or bottom margin of every page, and automatic margins grow to fit it.

```tsx twoslash title="Repeat a page footer"
import type { ReactNode } from "react";
declare const report: ReactNode;
// ---cut---
import { render } from "takumi-pdf";
import { PageNumber, TotalPages } from "takumi-pdf/primitives";

const pdf = await render(report, {
  // [!code highlight]
  footer: (
    <div tw="flex w-full justify-center text-[10px] text-gray-500">
      Page <PageNumber /> of <TotalPages />
    </div>
  ),
});
```

## Pages that differ

`pages` overrides the header or footer on some pages. Each page looks up a band in this order:

1. `first` or `last`
2. `odd` or `even`
3. the top-level `header` or `footer`

`false` leaves that band empty. Pages count from 1 over the whole document, before `pageRanges` drops any.

```tsx twoslash title="No header on the cover, a closing note on the last page"
import type { ReactNode } from "react";
declare const invoice: ReactNode;
// ---cut---
import { render } from "takumi-pdf";
import { PageNumber } from "takumi-pdf/primitives";

const pdf = await render(invoice, {
  header: <p>Acme Ltd</p>,
  footer: <PageNumber />,
  // [!code highlight:11]
  pages: {
    first: { header: false },
    last: {
      footer: (
        <div>
          <p>Thank you for your business.</p>
          <p>Terms: net 30.</p>
        </div>
      ),
    },
  },
});
```

Automatic margins fit the tallest band on every page, so a taller last-page footer does not change where the other pages break. A one-page document is its own first and last page, and `first` wins.

## Sizing the margin

`margin` defaults to `"auto"`. The renderer measures the header and footer at full page width. Each automatic top or bottom margin is the band height plus a 20px inset, and at least 37.8px. Left and right margins are 37.8px. A numeric margin overrides that side, and sides left out of the object stay automatic:

```ts title="Override the top margin"
const margin = { top: 96 };
```

<Callout type="warn">A numeric margin that is too small lets the band overlap the body.</Callout>

To compute a safe margin, call `measure()` with the same page size and fonts as the render. It lays the band out at full page width with three-digit page counters. Add the 20px inset to the returned height.

```tsx twoslash title="Measure a footer margin"
declare const report: import("react").ReactNode;
// ---cut---
import { googleFonts } from "@takumi-rs/helpers";
import { measure, render } from "takumi-pdf";
import { PageNumber, TotalPages } from "takumi-pdf/primitives";

const fonts = await googleFonts(["Inter"]);
const footer = (
  <div style={{ fontFamily: "Inter", fontSize: 10, textAlign: "center" }}>
    Page <PageNumber /> of <TotalPages />
  </div>
);

const { height } = await measure(footer, { size: "a4", fonts }); // [!code highlight]
const pdf = await render(report, {
  size: "a4",
  fonts,
  footer,
  margin: { bottom: height + 20 }, // [!code highlight]
});
```

Passing `viewport` instead of a page size measures the tree as-is. Counter hooks stay empty.

## Page counters

`<PageNumber />` is the current page, counting from 1, and `<TotalPages />` is the number of pages in the document. Both take a `format` prop for a [counter style](#counter-styles), and pass `className`, `style`, and `tw` through.

Each primitive renders a `<span>` with a class hook. A node with the `pageNumber` or `totalPages` class receives the counter text in place of its children, so an empty `<span />` is enough. Chromium's print templates use the same two class names. In HTML input, write the classes directly:

```html title="Page counters in HTML"
Page <span class="pageNumber"></span> of <span class="totalPages"></span>
```

A node with both classes gets the page number.

## Counters outside a band

Counters also work in document content. A `position: fixed` box repeats on every page, so a `<PageNumber />` inside it shows each page's number:

```tsx title="Page counters in a fixed box"
<div style={{ position: "fixed", bottom: 24, left: 24, right: 24 }}>
  Page <PageNumber /> of <TotalPages />
</div>
```

<Callout type="warn">
  A fixed box draws over the content, not in the margin, so leave room for it. Automatic margins fit
  only the header and footer.
</Callout>

In ordinary flow, `<PageNumber />` shows the page the counter lands on. Its value depends on pagination, so the document lays out again after the numbers are filled in.

## Counter styles

The `format` prop names a CSS `@counter-style`. On a class hook, add the style name as another class. The first supported name wins, unsupported names are ignored, and a counter without one uses `decimal`.

```tsx twoslash title="Format page numbers"
import type { ReactNode } from "react";
declare const report: ReactNode;
// ---cut---
import { render } from "takumi-pdf";
import { PageNumber, TotalPages } from "takumi-pdf/primitives";

const pdf = await render(report, {
  footer: (
    <div style={{ fontSize: 12 }}>
      {/* [!code highlight:2] */}
      第 <PageNumber format="trad-chinese-informal" /> 頁，共{" "}
      <TotalPages format="trad-chinese-informal" /> 頁
    </div>
  ),
});
```

### Numbers and numerals

| Style                   | Page 7 | Page 12 |
| ----------------------- | ------ | ------- |
| `decimal` (default)     | 7      | 12      |
| `decimal-leading-zero`  | 07     | 12      |
| `lower-roman`           | vii    | xii     |
| `upper-roman`           | VII    | XII     |
| `cjk-decimal`           | 七     | 一二    |
| `trad-chinese-informal` | 七     | 十二    |
| `cjk-ideographic`       | 七     | 十二    |

Blink defines `cjk-ideographic` as an extension of `trad-chinese-informal`, and takumi follows it. Both write numbers up to 9999 in words. Past that they fall back to `cjk-decimal`, so page 10000 formats as `一零零零零`.

### Alphabets

These styles count the way a spreadsheet names its columns. The letter after `z` is `aa`.

| Style                        | Page 12 |
| ---------------------------- | ------- |
| `lower-alpha`, `lower-latin` | l       |
| `upper-alpha`, `upper-latin` | L       |
| `lower-greek`                | μ       |
| `hiragana`                   | し      |
| `katakana`                   | シ      |

### Other digits

These styles write the decimal number in another script's digits.

| Style          | Page 12 | Style       | Page 12 |
| -------------- | ------- | ----------- | ------- |
| `arabic-indic` | ١٢      | `mongolian` | ᠑᠒      |
| `bengali`      | ১২      | `myanmar`   | ၁၂      |
| `cambodian`    | ១២      | `oriya`     | ୧୨      |
| `devanagari`   | १२      | `persian`   | ۱۲      |
| `gujarati`     | ૧૨      | `tamil`     | ௧௨      |
| `gurmukhi`     | ੧੨      | `telugu`    | ౧౨      |
| `kannada`      | ೧೨      | `thai`      | ๑๒      |
| `khmer`        | ១២      | `tibetan`   | ༡༢      |
| `lao`          | ໑໒      | `urdu`      | ۱۲      |
| `malayalam`    | ൧൨      |             |         |

`khmer` and `cambodian` share their digits, as do `persian` and `urdu`.

Register a font that covers the digits of the style you pick. Latin fonts rarely include Thai or Tibetan digits.

## Band height

A band with a counter is measured again with the real page count, up to three passes, and automatic margins use the final height. Give counters enough width that a longer page count does not wrap the band to a new line.
