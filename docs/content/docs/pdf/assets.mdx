---
title: Fonts & images
description: Load fonts and images into a PDF render, and choose what happens to characters no font covers.
---

Pass fonts through `fonts` and image bytes through `images`. The renderer fetches neither on its own. Font URL loaders and `googleFonts()` make their own requests, and you fetch document images before rendering.

## Fonts

```tsx twoslash title="Fonts"
import type { ReactNode } from "react";
declare const doc: ReactNode;
declare const fontBytes: Uint8Array;
// ---cut---
import { render } from "takumi-pdf";

import { googleFonts } from "@takumi-rs/helpers";

const pdf = await render(doc, {
  // [!code highlight:2]
  fonts: [...(await googleFonts(["Inter"])), { name: "Brand Sans", weight: 700, data: fontBytes }],
  fontFamilies: ["Brand Sans", "Inter", "sans-serif"],
});
```

`fonts` takes font URLs, raw bytes, descriptors, or [`googleFonts()`](/docs/fonts#from-google-fonts) entries. `fontFamilies` sets the fallback chain. A reused renderer loads each font once.

For offline renders, [bundle font files](/docs/fonts#fonts-in-ci-and-offline-renders). Google Fonts requests use the shared [fetch limits and retries](/docs/images#fetch-limits).

### Coverage

The renderer does not read system fonts. Its only built-in font is Geist, a last-resort face for Latin text. By default, a character that no registered font covers fails the render, and the error names the character and its codepoint. Register fonts for every script you use. Google Fonts can split accented letters between its `latin` and `latin-ext` subsets.

### Family names

<Callout type="warn">
  Quote a family name when one of its words starts with a digit, such as `fontFamily: '"Source Serif
  4"'`. Unquoted, `Source Serif 4` is not a valid `font-family` value. The declaration is dropped
  and the text falls back to the next family.
</Callout>

## Uncovered text

`uncoveredText` sets what happens to a character that no registered font covers:

| Value               | Result                                                     |
| ------------------- | ---------------------------------------------------------- |
| `"error"` (default) | Fails the render, naming each character and its codepoint. |
| `"placeholder"`     | Draws the font's glyph 0, which the font may leave empty.  |
| `"blank"`           | Draws nothing.                                             |

Neither `"placeholder"` nor `"blank"` reflows the line. The character keeps the width it had during layout.

```tsx twoslash title="Render with uncovered characters"
import type { ReactNode } from "react";
declare const doc: ReactNode;
// ---cut---
import { render } from "takumi-pdf";

const pdf = await render(doc, { uncoveredText: "placeholder" });
```

### Standards forbid the placeholder

Every PDF/A level and both PDF/UA levels forbid glyph 0, so `"placeholder"` fails the render with any `pdfa` level, `tagged: "ua1"`, or `tagged: "ua2"`. The error names the uncovered characters and the standard, and `"blank"` is the value to use there. See [PDF/A & PDF/UA](/docs/pdf/conformance).

### What copied text keeps

Whether an uncovered character survives in copied text depends on its shaping cluster, for `"placeholder"` and `"blank"` alike.

| Uncovered character                  | Copied text                                            |
| ------------------------------------ | ------------------------------------------------------ |
| On its own                           | Nothing. A PDF carries no Unicode mapping for glyph 0. |
| A combining mark on a covered letter | The mark, through the letter it shares a cluster with. |

## Images

Pass the bytes for each image URL in the document. The renderer does not fetch them:

```tsx twoslash title="Images"
import type { ReactNode } from "react";
declare const doc: ReactNode;
declare const logoUrl: string;
// ---cut---
import { render } from "takumi-pdf";

const response = await fetch(logoUrl);
if (!response.ok) throw new Error(`Logo request failed: ${response.status}`);
const logoBytes = new Uint8Array(await response.arrayBuffer());

const pdf = await render(doc, {
  // [!code highlight]
  images: [{ src: logoUrl, data: logoBytes }],
});
```

To fetch every remote image a document draws at once, use [`prepare()`](/docs/pdf/migration/puppeteer#fetching-moves-to-your-code).

### Formats

| Source | In the PDF                                                                                                                         |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| SVG    | Vector paths and gradients. Parts vectors cannot express, such as filters and embedded bitmaps, rasterize at 2× their placed size. |
| PNG    | Embedded as an image                                                                                                               |
| JPEG   | Embedded as the bytes you passed, keeping their compression                                                                        |
| WebP   | Embedded as an image                                                                                                               |
| GIF    | Rejected, since the PDF build ships no GIF decoder                                                                                 |

Identical raster images are embedded once.

### Filters

A CSS color filter on an image needs decoded pixels, and the PDF build decodes only PNG. A filtered JPEG or WebP image fails the render. PDF output also rejects `filter: blur()` and `drop-shadow()`, naming the function in the error. Bake those effects into a raster image before rendering.
