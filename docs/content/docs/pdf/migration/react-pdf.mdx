---
title: From react-pdf
description: Move a @react-pdf/renderer template to takumi-pdf by mapping each component and option, converting units, and registering fonts and images.
---

To migrate, replace react-pdf's primitives with HTML elements, move page settings into `render()` options, and convert lengths from pt to CSS px. The resulting JSX also renders as an image with [`takumi-js`](/docs).

## Before and after

```tsx title="Before: react-pdf primitives"
// @react-pdf/renderer
import { Document, Page, View, Text, StyleSheet, renderToBuffer, Font } from "@react-pdf/renderer";

Font.register({ family: "Inter", src: "./Inter-Regular.ttf" });

const styles = StyleSheet.create({
  page: { padding: 48, fontFamily: "Inter" },
  row: { flexDirection: "row", justifyContent: "space-between" },
  label: { fontSize: 10, color: "#6b7280" },
});

const pdf = await renderToBuffer(
  <Document>
    <Page size="A4" style={styles.page}>
      <View style={styles.row}>
        <Text style={styles.label}>Invoice</Text>
        <Text style={styles.label}>INV-0042</Text>
      </View>
    </Page>
  </Document>,
);
```

```tsx twoslash title="After: HTML elements and CSS"
// takumi-pdf
import { googleFonts } from "@takumi-rs/helpers";
import { render } from "takumi-pdf";

const pdf = await render(
  <div tw="flex justify-between text-gray-500" style={{ fontSize: (10 * 96) / 72 }}>
    <span>Invoice</span>
    <span>INV-0042</span>
  </div>,
  // [!code highlight]
  { size: "a4", margin: 64, fonts: await googleFonts(["Inter"]) },
);
```

## Component map

| `@react-pdf/renderer`                   | `takumi-pdf`                                     |
| --------------------------------------- | ------------------------------------------------ |
| `<Document>`                            | none, since `render()` takes the tree            |
| `<Page size="A4">`                      | the `size` option                                |
| `<View>`                                | `<div>`                                          |
| `<Text>`                                | `<span>`, `<p>`, or bare text                    |
| `<Image src>`                           | `<img src>` plus the `images` option             |
| `<Link src>`                            | `<a href>`                                       |
| `<Svg>` primitives                      | `<svg>`, or an SVG through `images`              |
| `StyleSheet.create`                     | `style` objects or `tw` classes                  |
| `Font.register`                         | the `fonts` option                               |
| `renderToBuffer`                        | `render()` returns a `Uint8Array`                |
| `renderToStream`, `renderToFile`        | write the returned bytes yourself                |
| a `fixed` header or footer `<View>`     | the `header` and `footer` options                |
| `render={({ pageNumber, totalPages })}` | `<PageNumber />` and `<TotalPages />`            |
| the `break` prop                        | `break-before: page`                             |
| `wrap={false}`                          | `break-inside: avoid`                            |
| `orphans`, `widows`                     | the same CSS properties                          |
| `minPresenceAhead`                      | not supported                                    |
| `Font.registerHyphenationCallback`      | not supported                                    |
| `Font.registerEmojiSource`              | `extractEmojis`, then `prepareImages`            |
| `<PDFViewer>`, `<PDFDownloadLink>`      | render bytes, then provide a preview or download |

## Preserve the layout

### Units are CSS px

react-pdf measures lengths in pt. Takumi measures them in CSS px at 96 dpi, so multiply every length by `96 / 72`, about `1.333`. A4 is `595 × 842` pt, or `794 × 1123` px. Unitless values such as `flexGrow`, `opacity`, and `fontWeight` carry over unchanged.

### Flex direction defaults to row

react-pdf defaults every container to `column`. CSS defaults to `row`, so a stacked layout needs `flex-direction: column` written out.

### Flex layout is opt-in

react-pdf's `<View>` is always a flex container. A plain HTML element is not, so a `<div>` that lays out children needs `display: flex` or `display: grid`. In Tailwind, write `tw="flex flex-col"`.

## Page bands

react-pdf repeats a band by marking a `<View>` inside the page as `fixed`. Takumi takes the band as a separate option and draws it in the margin:

```tsx twoslash title="Repeat page headers"
import type { ReactNode } from "react";
declare const report: ReactNode;
// ---cut---
import { render } from "takumi-pdf";
import { PageNumber, TotalPages } from "takumi-pdf/primitives";

const pdf = await render(report, {
  // [!code highlight]
  footer: (
    <div tw="flex w-full justify-center text-[10px] text-gray-500">
      Page <PageNumber /> of <TotalPages />
    </div>
  ),
  margin: { top: 48, bottom: 72 },
});
```

The counter is a class on an element, not a `render` callback. See [Headers & footers](/docs/pdf/headers) for counter styles and for sizing the margin to the band.

## Known gaps

Takumi has no equivalent for `minPresenceAhead`, hyphenation callbacks, or react-pdf's preview and download components. Render a `Uint8Array` and deliver it from your application. In a browser bundle, use the [manual initialization entry](/docs/pdf#in-the-browser). `widows` and `orphans` do work, as CSS properties, and [Pagination](/docs/pdf/pagination#widows-and-orphans) covers them. For archival output and accessibility validation, see [PDF/A & PDF/UA](/docs/pdf/conformance).
