---
title: render()
description: Every option render() takes, grouped by what it sets, and what it returns.
---

`render()` lays out JSX, an HTML string, or a node tree across pages and resolves to the PDF bytes, a `Uint8Array`.

```ts twoslash title="Render a document"
import { render } from "takumi-pdf";

const pdf = await render("<h1>Invoice 1042</h1>", { size: "letter", outline: true });
```

It uses one renderer shared by every call. To keep a font registry of your own, call `render()` on a [`PdfRenderer`](/docs/pdf/reference/renderer), which takes the same options.

The types reject combinations a standard forbids. For example, `pdfa: "2a"` with `tagged: false`, or `attachments` with a PDF/A-2 level, fail to typecheck. See [Compatible options](/docs/pdf/conformance#compatible-options).
