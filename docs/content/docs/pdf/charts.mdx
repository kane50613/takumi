A chart in a PDF needs vector lines and shapes, fonts that cover its labels, and a description of its data. Embed the chart as SVG to keep its lines and shapes as vectors, and generate the SVG before rendering the document. For a complete ECharts example, see [Charts](/docs/charts#render-an-echarts-chart).

## Add a chart

Pass the SVG string to `src` and set its size in CSS px.

```tsx twoslash title="Add a chart"
declare const svg: string;
// ---cut---
import { googleFonts, render } from "takumi-pdf";

const pdf = await render(
  <figure style={{ margin: 0, breakInside: "avoid" }}>
    <img
      src={svg}
      alt="Quarterly revenue: 320, 730, 550, and 910"
      style={{ width: 560, height: 360 }}
    />
    <figcaption>Revenue by quarter</figcaption>
  </figure>,
  { size: "a4", fonts: await googleFonts(["Inter"]) },
);
```

Replace `svg` with your generated chart. `breakInside: "avoid"` keeps the chart and caption on one page when they fit. Pick a size that fits inside the page margins. [Pagination](/docs/pdf/pagination) lists every break property.

## Fonts for chart labels

`render()` reads the text inside an SVG image, so a font that only chart labels use still loads. Pass fonts that cover every label, tick, and legend entry through `fonts`:

```tsx twoslash title="Load chart label fonts"
declare const svg: string;
// ---cut---
import { googleFonts, render } from "takumi-pdf";

const pdf = await render(<img src={svg} alt="營收" style={{ width: 560, height: 360 }} />, {
  fonts: await googleFonts(["Noto Sans TC"]), // [!code highlight]
});
```

Set the chart library's font family to the same name, here `"Noto Sans TC"`. [Fonts & images](/docs/pdf/assets) covers font loading in full.

## Vector output and text

- SVG paths, supported gradients, and dashed lines stay vector.
- Embedded bitmaps, and SVG effects that need rasterizing, become pixels.
- A PNG chart stays raster in the PDF.

SVG labels are drawn as outlines. They stay visible, but readers cannot select, search, or copy them. Put titles, captions, and data tables that should be searchable in the surrounding JSX.

## Describe the data

Give the chart a meaningful `alt`. Tagged output uses it as the figure description. A label such as "Bar chart" names the image but says nothing about its data. [PDF/A & PDF/UA](/docs/pdf/conformance#tagged-output) describes how `alt` maps to the structure tree. For a detailed chart, add a table of the underlying values. See [Reports & statements](/docs/pdf/reports#long-tables) for a table that continues across pages.
