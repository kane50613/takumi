A ticket, shipping label, certificate, or receipt is a single page, so it needs a page size and no pagination. Use `viewport` and set both dimensions for a fixed paper size, or omit `height` for a receipt that grows with its content. The sections below cover each case.

## Labels and tickets

Give `viewport` the paper size in CSS px at 96 dpi. Percentage heights resolve against it, so a full-bleed background is `height: "100%"`.

```tsx twoslash title="Labels and tickets"
declare const qrSvg: Uint8Array;
// ---cut---
import { render } from "takumi-pdf";

// 4in × 6in shipping label
const pdf = await render(
  <div tw="flex h-full w-full flex-col justify-between bg-white p-6">
    <span tw="text-2xl font-semibold">ACME · Priority</span>
    <img src="qr.svg" alt="Tracking code" tw="h-40 w-40 self-center" />
    <span tw="text-xs text-gray-500">1Z 999 AA1 0123 4567</span>
  </div>,
  // [!code highlight]
  { viewport: { width: 384, height: 576 }, images: [{ src: "qr.svg", data: qrSvg }] },
);
```

Generate the QR code or barcode as SVG and pass its bytes through `images`. It stays vector at any print size. Check that the printed code is large enough, with enough clear space around it, to scan. [Fonts & images](/docs/pdf/assets) covers `images`.

The table lists common sizes in CSS px.

| Paper           | Width × height |
| --------------- | -------------- |
| A4 portrait     | 794 × 1123     |
| A4 landscape    | 1123 × 794     |
| A6 postcard     | 397 × 559      |
| 4in × 6in label | 384 × 576      |
| 80mm receipt    | 302 × auto     |

## Receipts

Omit `height` and the page grows to fit the content, so a till receipt is one continuous strip however many lines it has.

```tsx twoslash title="Receipts"
import type { ReactNode } from "react";
declare const receipt: ReactNode;
// ---cut---
import { render } from "takumi-pdf";

// [!code highlight]
const pdf = await render(receipt, { viewport: { width: 302 } }); // 80mm at 96 dpi
```

Percentage heights do not resolve in this mode, because the page height is known only after layout.

## Certificates

A certificate is a fixed page with artwork behind the text. Gradients, borders, border radii, and transforms all draw as vectors.

```tsx twoslash title="Certificates"
declare const recipient: string;
// ---cut---
import { render } from "takumi-pdf";

const pdf = await render(
  <div
    tw="flex h-full w-full flex-col items-center justify-center"
    // [!code highlight]
    style={{ backgroundImage: "linear-gradient(135deg, #eef2ff, #ffffff)" }}
  >
    <span tw="text-sm tracking-[0.3em] text-indigo-500">CERTIFICATE OF COMPLETION</span>
    <span tw="mt-6 text-5xl">{recipient}</span>
  </div>,
  { viewport: { width: 1123, height: 794 } },
);
```

<Callout type="warn">
  Content that overflows the page is clipped, as in an image render. Size the text to fit, or check
  it first with `measure()`.
</Callout>

## Options

`viewport` rules out the paged options, and TypeScript reports them as type errors. Every other option still works, including `pdfa` and `attachments`. See [Single-page PDFs](/docs/pdf/viewport) and [PDF/A & PDF/UA](/docs/pdf/conformance).

The same component also renders as a PNG with [`takumi-js`](/docs). Pass `width` and `height` to the image renderer instead of `viewport`.
