title: SvelteKit
description: Render Svelte components and their CSS as Open Graph images or PDFs in SvelteKit server routes.
---

Render a Svelte component to HTML on the server. Then pass that HTML and its CSS to `ImageResponse`.

<Steps>
  <Step>
    ### Install Takumi

    ```npm
    npm i takumi-js
    ```

  </Step>
  <Step>
    ### Make a Svelte component

    <Callout type="warn">Set `css="injected"` so the component's `<style>` block lands in the server-rendered HTML.</Callout>

    ```svelte title="src/lib/components/OgImage.svelte"
    <script lang="ts">
      let { name = "Goo goo gaga" } = $props();
    </script>

    <!-- [!code highlight] -->
    <svelte:options css="injected" />

    <div
      id="og-image"
      class="w-full h-full flex items-center justify-center p-12 flex-col gap-4"
    >
      <div class="text-center whitespace-pre-wrap leading-normal text-7xl font-semibold text-black">
        Welcome {name} to
        <span class="font-bold">Svelte</span> world
      </div>
    </div>

    <style>
      #og-image {
        background-image: linear-gradient(to bottom right, var(--color-orange-50), var(--color-red-200));
      }
    </style>
    ```

  </Step>
  <Step>
    ### Render the component on a server route

    Render the component with `render` from `svelte/server`, then return an `ImageResponse`. If you use Tailwind, import `app.css` with `?inline` and pass it as `css`.

    The example imports through `#lib/*`. Map it to `./src/lib/*` in the `imports` field of `package.json`.

    ```ts title="src/routes/+server.ts"
    import { render } from "svelte/server";
    import style from "../app.css?inline";
    import ImageResponse from "takumi-js/response";
    import OgImage from "#lib/components/OgImage.svelte";
    import type { RequestEvent } from "./$types";

    export async function GET({ url }: RequestEvent) {
      const { body, head } = await render(OgImage, {
        props: {
          name: url.searchParams.get("name") ?? "Goo goo gaga",
        },
      });

      return new ImageResponse(`${head}${body}`, {
        width: 1200,
        height: 630,
        // [!code highlight]
        css: style,
        fonts: ["https://takumi.kane.tw/fonts/Geist.woff2"],
      });
    }
    ```

    `head` carries the injected `<style>`, and `body` carries the markup. `fonts` takes a font URL, which Takumi fetches on demand.

  </Step>
</Steps>

## Render a PDF

The same component HTML renders to a PDF with [`takumi-pdf`](/docs/pdf). Install it, then return its bytes from a server route.

```npm
npm i takumi-pdf
```

```ts title="src/routes/invoice.pdf/+server.ts"
import { render as renderSvelte } from "svelte/server";
import { render } from "takumi-pdf";
import Invoice from "#lib/components/Invoice.svelte";

export async function GET() {
  const { head, body } = await renderSvelte(Invoice, {
    props: { id: 1042 },
  });

  const pdf = await render(`${head}${body}`, {
    size: "a4",
    fonts: ["https://takumi.kane.tw/fonts/Geist.woff2"],
  });

  return new Response(pdf, {
    headers: { "content-type": "application/pdf" },
  });
}
```

Content longer than a page flows onto the next one. See [Pagination](/docs/pdf/pagination) to control the breaks and [Headers & footers](/docs/pdf/headers) to repeat page numbers.

## Deploy to Cloudflare

`@sveltejs/adapter-cloudflare` 8.0.3 resolves server code for Cloudflare Workers but leaves out the plugin that loads `.wasm` imports. Both `vite dev` and `vite build` then stop with this error:

```
Failed to load url ./takumi_wasm_bg.js (resolved id: ./takumi_wasm_bg.js) in .../@takumi-rs/wasm/pkg/takumi_wasm_bg.wasm. Does the file exist?
```

Pin the adapter to 8.0.2 until a later release loads `.wasm` imports again. [Issue #2645](https://github.com/kane50613/takumi/issues/2645) tracks the fix.

```npm
npm i -D @sveltejs/adapter-cloudflare@8.0.2
```
