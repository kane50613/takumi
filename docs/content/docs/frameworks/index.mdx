Choose the guide for your framework. Each guide covers what the integration does, installation, the route or config, and what to read next.

- [Next.js](/docs/frameworks/nextjs) renders Open Graph images from React components in App Router route handlers.
- [Fumapress](/docs/frameworks/fumapress) generates an Open Graph image and metadata for every docs page with its built-in Takumi plugin.
- [Nuxt](/docs/frameworks/nuxt) renders Open Graph images from Vue templates through Nuxt OG Image.
- [SvelteKit](/docs/frameworks/sveltekit) renders Svelte components and their CSS in server routes.
- [TanStack Start](/docs/frameworks/tanstack-start) renders Open Graph images from React components in server file routes.
- [Nitro](/docs/frameworks/nitro) returns Open Graph images from server routes.
- [Astro](/docs/frameworks/astro) generates an Open Graph image for every static page at build time with astro-takumi.
- [Cloudflare Workers](/docs/frameworks/cloudflare-workers) renders images in a Worker on the WebAssembly backend.
- [Bun single-file executable](/docs/frameworks/bun-compile) embeds the native addon in an executable from `bun build --compile`.
