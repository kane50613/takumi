---
title: Nuxt
description: Use Takumi through Nuxt OG Image in Nuxt apps.
---

The recommended integration is [Nuxt OG Image](https://nuxtseo.com/docs/og-image/getting-started/introduction) with its [Takumi renderer](https://nuxtseo.com/docs/og-image/renderers/takumi). It already knows how to render Vue components as OG images.

<Steps>
  <Step>
    ### Add the Nuxt module and the runtime binding

    ```bash
    npx nuxt module add og-image
    npm install -D @takumi-rs/core
    ```

    For edge runtimes (Cloudflare Workers, Vercel Edge) install `@takumi-rs/wasm` instead.

  </Step>
  <Step>
    ### Set Takumi as the renderer

    ```ts title="nuxt.config.ts"
    export default defineNuxtConfig({
      ogImage: {
        defaults: {
          renderer: "takumi",
        },
      },
    });
    ```

  </Step>
  <Step>
    ### Write a `.takumi.vue` template

    Nuxt OG Image picks up the Takumi renderer from the suffix.

    ```vue title="components/OgImage/BlogPost.takumi.vue"
    <script setup lang="ts">
    defineProps<{
      title: string;
      description?: string;
    }>();
    </script>

    <template>
      <div class="w-full h-full flex flex-col justify-center bg-gray-950 text-white p-16">
        <p class="text-6xl font-bold leading-tight">
          {{ title }}
        </p>
        <p v-if="description" class="mt-6 text-2xl text-gray-400">
          {{ description }}
        </p>
      </div>
    </template>
    ```

  </Step>
  <Step>
    ### Attach the template to a page

    ```vue title="pages/blog/[slug].vue"
    <script setup lang="ts">
    defineOgImageComponent("BlogPost", {
      title: "Takumi + Nuxt",
      description: "Render OG images with Nuxt OG Image.",
    });
    </script>
    ```

  </Step>
</Steps>
