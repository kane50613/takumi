Measure runs the layout pass and returns box dimensions without rasterizing pixels. Cheap enough to call many times per request.

```tsx twoslash tab="takumi-js/node"
import { Renderer } from "takumi-js/node";
import { fromJsx } from "takumi-js/helpers/jsx";

const renderer = new Renderer();
const { node, stylesheets } = await fromJsx(<span tw="text-xl">I'm a text node</span>);

// [!code ++]
const { width, height } = await renderer.measure(node, { stylesheets });
```


## When to use Measure

Three concrete cases where measuring before rendering pays for itself.

### Text-fitting

Pick a font size so a headline fills its box without overflowing. Binary-search font size, measuring after each guess, and only call `render` once you've landed on the right value.

```tsx twoslash
// @noErrors
import { Renderer } from "takumi-js/node";
import { fromJsx } from "takumi-js/helpers/jsx";

const renderer = new Renderer();
const targetWidth = 800;
const headline = "Takumi 1.2 comes with text-fit property support";

let lo = 16;
let hi = 200;
while (hi - lo > 1) {
  const mid = (lo + hi) >> 1;
  const { node, stylesheets } = await fromJsx(
    <span style={{ fontSize: mid, whiteSpace: "nowrap" }}>{headline}</span>,
  );
  const { width } = await renderer.measure(node, { stylesheets });
  if (width > targetWidth) hi = mid;
  else lo = mid;
}
```

The CSS `text-fit` property (see the [text-fit example](https://github.com/kane50613/takumi/blob/master/example/twitter-images/components/text-fit.tsx)) does this inside the engine. Reach for `measure` when you need the result in user space — e.g. to pick between alternate copy.

### Responsive cards

A product card's height depends on its title length, description length, and image aspect ratio. Measure once with `width` fixed to learn the natural height, then pass that into `render`.

```tsx twoslash
// @noErrors
import { Renderer } from "takumi-js/node";
import { fromJsx } from "takumi-js/helpers/jsx";

const renderer = new Renderer();
const { node, stylesheets } = await fromJsx(<ProductCard />);

const { height } = await renderer.measure(node, { width: 600, stylesheets });
const png = await renderer.render(node, { width: 600, height, stylesheets });
```

### Layout-aware truncation

Decide whether to add an ellipsis or drop the third paragraph entirely based on what fits. Measure the full content, compare against the budget, render the trimmed version.
