Takumi renders JSX, HTML, and node trees into images — PNG, JPEG, WebP, SVG, and animations — through a real CSS layout pipeline written in Rust.

Generate OG images and social cards without a headless browser:

- **No Chromium.** No 300 MB browser process per render. Native Rust on the server, WebAssembly on the edge.
- **Drop-in for `next/og`.** `ImageResponse` matches the API you already ship.
- **Real CSS, not a subset.** Flexbox, Grid, and block layout, where satori is flex-only.
- **One engine, every output.** Raster, vector SVG, and animated GIF or WebP from the same render.

## Install

```npm
npm i takumi-js@beta
```

On Node.js this pulls the native renderer (`@takumi-rs/core`). For Cloudflare Workers, Vercel Edge, Deno, or the browser, add the WebAssembly binding and `takumi-js` loads it for you:

```npm
npm i @takumi-rs/wasm@beta
```

## Render an image

`render` takes JSX and returns image bytes. Geist is built in, so text works without loading a font.

```tsx
import { render } from "takumi-js";
import { writeFile } from "node:fs/promises";

const png = await render(
  <div
    style={{
      width: "100%",
      height: "100%",
      display: "flex",
      alignItems: "center",
      justifyContent: "center",
      fontSize: 72,
      background: "linear-gradient(to bottom right, #fff7ed, #fecaca)",
    }}
  >
    Hello Takumi
  </div>,
  { width: 1200, height: 630 },
);

await writeFile("hello.png", png);
```

The `width` and `height` set the canvas. The root doesn't fill it on its own, so it carries `width: 100%` and `height: 100%`.

## Serve it over HTTP

For an OG image endpoint, return an `ImageResponse`. It extends the web `Response`, so any runtime with `Request` and `Response` can return it. The API matches `next/og`.

```tsx twoslash
import { ImageResponse } from "takumi-js/response";

export function GET() {
  return new ImageResponse(<div style={{ width: "100%", height: "100%" }}>Hello Takumi</div>, {
    width: 1200,
    height: 630,
  });
}
```

<Callout type="warning">
  Takumi never reads system fonts. Geist ships built in; load every other font through `fonts` or
  its glyphs render as tofu. See [Fonts](/docs/typography-and-fonts).
</Callout>

## Coming from satori

`ImageResponse` is a drop-in for `next/og`. The layout defaults differ: a bare `<div>` is `block` where satori forces `display: flex`, and `flex-direction` defaults to `row` instead of satori's `column`. Takumi also rasterizes directly instead of returning an SVG to convert.
