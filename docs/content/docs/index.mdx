Takumi turns JSX, HTML, and node trees into PNG, JPEG, WebP, SVG, and animated images. It runs a real CSS layout and compositing pipeline in Rust, so you get browser-grade output without a headless Chromium eating 300 MB of RAM.

## Install

```npm
npm i takumi-js@beta
```

On Node.js this pulls the native renderer (`@takumi-rs/core`). For Cloudflare Workers, Vercel Edge, Deno, or the browser, add the WebAssembly binding and `takumi-js` loads it for you:

```npm
npm i @takumi-rs/wasm@beta
```

## Render an image

`render` takes JSX and returns image bytes. Geist is built in, so text works without loading a font.

```tsx
import { render } from "takumi-js";
import { writeFile } from "node:fs/promises";

const png = await render(
  <div
    style={{
      width: "100%",
      height: "100%",
      display: "flex",
      alignItems: "center",
      justifyContent: "center",
      fontSize: 72,
      background: "linear-gradient(to bottom right, #fff7ed, #fecaca)",
    }}
  >
    Hello Takumi
  </div>,
  { width: 1200, height: 630 },
);

await writeFile("hello.png", png);
```

The `width` and `height` set the canvas. The root doesn't fill it on its own, so it carries `width: 100%` and `height: 100%`.

## Serve it over HTTP

For an OG image endpoint, return an `ImageResponse`. It extends the web `Response`, so any runtime with `Request` and `Response` can return it. The API matches `next/og`.

```tsx twoslash
import { ImageResponse } from "takumi-js/response";

export function GET() {
  return new ImageResponse(<div style={{ width: "100%", height: "100%" }}>Hello Takumi</div>, {
    width: 1200,
    height: 630,
  });
}
```

<Callout type="warning">
  Takumi never reads system fonts. Geist ships built in; load every other font through `fonts` or
  its glyphs render as tofu. See [Fonts](/docs/typography-and-fonts).
</Callout>

## Coming from satori

`ImageResponse` is a drop-in for `next/og`, and Takumi rasterizes directly instead of handing you an SVG to convert. Two layout defaults differ: Takumi runs Flexbox, Grid, and block with real browser defaults, where satori is flex-only and forces `display: flex` with a `column` default. A bare `<div>` is a block, and `flex-direction` defaults to `row`.
