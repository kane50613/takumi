Takumi is a high-performance image renderer in Rust, featuring JSX support and portable runtimes.
This guide will get you up and running with the high-level `ImageResponse` API in just a few steps.

## 1. Install

```npm
npm i @takumi-rs/image-response@beta
```

### Extra bundlers config for Node.js

For Next.js users, before [the PR merged](https://github.com/vercel/next.js/pull/91899), you would need to mark Takumi's Node.js bindings as external so it bundles correctly.

```tsx title="next.config.ts"
const config: NextConfig = {
  // [!code ++]
  serverExternalPackages: ["@takumi-rs/core"],
};

export default config;
```

## 2. Return an `ImageResponse`

`ImageResponse` extends the standard [Response](https://developer.mozilla.org/en-US/docs/Web/API/Response), so you can use it in any environment you want.

```tsx twoslash
/** @jsxImportSource react */
// ---cut-before---
import { ImageResponse } from "@takumi-rs/image-response";

export function GET() {
  return new ImageResponse(
    <div tw="w-full h-full flex items-center justify-center bg-white">
      <h1 tw="text-4xl font-bold">Hello Takumi 👋😁</h1>
    </div>,
    {
      width: 1200,
      height: 630,
      format: "webp",
      emoji: "twemoji", // Available since 1.0.0-beta.3
      headers: {
        "Cache-Control": "public, max-age=3600",
      },
    },
  );
}
```

Internally, Takumi will tries to load the native bindings for your platform. If it fails, it will fallback to the WebAssembly version, which is slightly slower but works everywhere.

## Templates

Need a fast starting point? Use built-in [Templates](/docs/templates) from the registry:

