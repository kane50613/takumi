---
title: measure()
description: Measure the size, position, and text runs of laid-out nodes with measure() without painting.
---

`measure()` lays out a tree and returns each box's size and position without painting it. Use it to place a badge next to a measured box. To fit a headline into a fixed width, set [`text-fit`](/docs/typography#fit-to-container) on it instead, which scales the text in one render.

```tsx twoslash title="Measure an element"
import { measure } from "takumi-js";

const { width, height } = await measure(<span tw="text-xl">I'm a text node</span>); // [!code highlight]
//      ^?
```

`measure()` takes the same input and options as `render()`: JSX, an HTML string, or a node tree, with `css`, `fonts`, and `images`. It runs on the same default renderer, so fonts loaded for rendering measure the same way. Without `width` and `height`, the root sizes to its content.

Use `measure()` for sizes and positions. To draw the laid-out boxes and text yourself, use [`takumi-paint`](/docs/paint), which returns the shapes, text runs, and images to draw, in order, with every CSS value resolved.

## Returned fields

`measure()` resolves to a `MeasuredNode`.

<TypeTable
  type={{
    width: {
      type: "number",

    },
    height: {
      type: "number",
      description: "Laid-out height",
    },
    transform: {
      type: "[number, number, number, number, number, number]",
      description: "Matrix that places the box in the image",
    },
    children: {
      type: "MeasuredNode[]",

    runs: {
      type: "MeasuredTextRun[]",

    },

/>

<Callout type="info">
  Lengths are in device pixels. A `20px` box measures `40` with a `devicePixelRatio` of `2`.
</Callout>

## Coordinates

`transform` is absolute and places the box in the image. Every node has one, including the boxes Takumi generates to lay out inline content.

A run's `x` and `y` are not absolute. They start at the content box of the node that owns the run. To place a run in the image, add that node's `padding` and `border` to the run's `x` and `y`, then apply the node's `transform`.
