Takumi's packages export helpers that build node trees and load fonts. Import each one from the package you render with:

| Package                                 | Helpers                                                                                          |
| :-------------------------------------- | :----------------------------------------------------------------------------------------------- |
| `takumi-js`                             | `googleFonts`, `container`, `text`, `image`, `Bitmap`                                            |
| `takumi-pdf`                            | `googleFonts`                                                                                    |
| `@takumi-rs/core` and `@takumi-rs/wasm` | `fromJsx`, `googleFonts`, `fontFromUrl`, `extractEmojis`, `container`, `text`, `image`, `Bitmap` |

```ts twoslash title="Build a node tree"
import { container, text } from "takumi-js";

const node = container({
  style: { padding: 32, backgroundColor: "white" },
  children: [text("Hello Takumi", { fontSize: 48 })],
});
```

`render` and `ImageResponse` already convert JSX and HTML and load the images they use, so use these helpers to build node trees or load fonts yourself. `@takumi-rs/helpers` and the `takumi-js/helpers` entries still export them, but both are deprecated, and `@takumi-rs/helpers` becomes internal in v3.

## Fonts

| Helper                       | Use                                                     |
| :--------------------------- | :------------------------------------------------------ |
| `googleFonts(options)`       | Load Google Fonts families in one request. <sup>1</sup> |
| `fontFromUrl(url, options?)` | Turn a font URL into a lazy `fonts` entry. <sup>2</sup> |

<sup>1</sup> `render` keeps only the subsets the text uses. See [Fonts &
text](/docs/fonts#from-google-fonts).

<sup>2</sup> `options` takes the [fetch limits](/docs/images#fetch-limits). Without them, pass the
URL string in `fonts` instead, which `takumi-js` and `takumi-pdf` take too.

`googleFonts` and `fontFromUrl` share [fetch limits and retry behavior](/docs/images#fetch-limits).

## Building nodes

| Helper                               | Returns           |
| :----------------------------------- | :---------------- |
| `container(props)`                   | A container node. |
| `text(text, style?)` / `text(props)` | A text node.      |
| `image(props)`                       | An image node.    |

The `props` argument holds the node's own fields. [Node types](/docs/reference#node-types) lists them. Styles, presets, and stylesheet rules share the `Declarations` type. Custom properties such as `"--accent": "red"` accept strings or numbers, including in React's `style` prop.

Write lengths and colors as CSS strings, such as `"50%"`, `"1.5rem"`, or `"rgb(0 0 0 / 0.5)"`.

## Converting JSX for a binding

A `Renderer` from `@takumi-rs/core` or `@takumi-rs/wasm` takes a node tree or an HTML string. Convert JSX with `fromJsx(element, options?)` from the same package, which returns `{ node, css }`:

```tsx
import { fromJsx, Renderer } from "@takumi-rs/core";

const { node, css } = await fromJsx(<div tw="flex text-4xl">Hello</div>);
const png = await new Renderer().render(node, { width: 1200, height: 630, css });
```

`fromJsx` resolves React hooks and context without `react-dom`. Components that call `useState`, `useContext`, or `use()` render with server semantics: initial state, no effects. Preact trees work only when their components call no Preact hooks.

## Emoji

`takumi-js` splits emoji out of the text through its `emoji` option. On a renderer binding, call `extractEmojis(node, emojiType)` to replace emoji with CDN `<img>` nodes, then call the renderer's `prepare`, which fetches them with the other images. See [Emoji](/docs/images#emoji).

`emojiType` takes the CDN values of the `emoji` option listed in [Image loading & emoji](/docs/images#dynamic-fetching). It does not take `from-font`, which fetches nothing.
