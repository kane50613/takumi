---
title: render()
description: Render JSX, HTML, or a node tree to image bytes with render(), and every option it, renderSvg(), and ImageResponse take.
---

`render()` lays out its input and returns the encoded image. It takes JSX, an HTML string, or a node tree.

```tsx twoslash title="Render a PNG"
import { render } from "takumi-js";

const png = await render(<div tw="w-full h-full bg-white">Hello</div>, {
  width: 1200,
  height: 630,
});
```

It resolves to a `Buffer` on the native backend, which Node.js and Bun use unless you pass `module`, and to a `Uint8Array` on WebAssembly. With `format: "raw"` the bytes are the RGBA pixels, four per pixel, row by row.

`renderSvg()` takes the same input and options, except the raster-only `format`, `quality`, `lossless`, `dithering`, `drawDebugBorder`, and `devicePixelRatio`, and resolves to an SVG document string. [`ImageResponse`](/docs/reference/image-response) and [`measure()`](/docs/reference/measure) take them too.

## renderAnimation()

`renderAnimation()` encodes a list of scenes as an animated WebP, APNG, or GIF. It takes one options object that holds `scenes` and requires `width`, `height`, and `fps`, and its `format` is `"webp"`, `"apng"`, or `"gif"` rather than the static formats above. See [Animation](/docs/animation#an-animated-image-with-renderanimation).
