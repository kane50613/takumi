## External Images

By default, Takumi will fetch external images in `src` attributes and CSS properties like `background-image` and `mask-image`.

If you want to add additional caching layer, you can fetch the image yourself and pass the data to `render()` with `fetchedResources`.

```tsx twoslash
/** @jsxImportSource react */
// ---cut-before---
import { fromJsx } from "takumi-js/helpers/jsx";
import { extractResourceUrls, render } from "takumi-js";
import { fetchResources } from "takumi-js/helpers";

const element = <img src="https://example.com/image.png" />;

// [!code ++:2]
const urls = await extractResourceUrls(element);
const fetchedResources = await fetchResources(urls);

const image = await render(element, {
  fetchedResources, // [!code ++]
  stylesheets,
});
```

## Persistent Images

Preload frequently used images like logo, background, etc. to avoid redundant image decoding and improve performance.

The image key can be used in any `src` field or `background-image`, `mask-image` CSS property.

```tsx twoslash
/** @jsxImportSource react */
// ---cut-before---
import { ImageResponse } from "takumi-js/response";
import type { ImageSource } from "takumi-js";

const [logo, background] = await Promise.all([
  fetch("/logo.png").then((res) => res.arrayBuffer()),
  fetch("/background.png").then((res) => res.arrayBuffer()),
]);

const persistentImages: ImageSource[] = [
  {
    src: "my-logo",
    data: logo,
  },
  {
    src: "background",
    data: background,
  },
];

export function GET() {
  return new ImageResponse(<OgImage />, {
    // [!code ++]
    persistentImages,
  });
}

function OgImage() {
  return (
    <div
      style={{
        backgroundImage: "url(background)",
      }}
    >
      <img src="my-logo" />
    </div>
  );
}
```
