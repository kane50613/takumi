### Publish takumi-pdf, the wasm PDF package

`render(jsx)` turns a node tree or JSX into a paged PDF with selectable text and embedded subset fonts, on Node, Bun, and Cloudflare Workers. Options cover a page `size` (`"a4"`, `"letter"`, `{ width, height }`) with `landscape` and a uniform margin, a fixed single-page `viewport`, repeating header/footer bands with `{page}`/`{pages}` counters, fonts, images, and stylesheets.
