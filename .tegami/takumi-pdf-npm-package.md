### Publish takumi-pdf, the wasm PDF package

`render(jsx)` turns a node tree or JSX into a paged PDF with selectable text and embedded subset fonts, on Node, Bun, and Cloudflare Workers. Options cover fixed single-page output, a CSS-style `size` (`"a4"`, `"letter landscape"`, `[width, height]`) with a uniform margin, repeating header/footer bands with `{page}`/`{pages}` counters, fonts, images, and stylesheets.
